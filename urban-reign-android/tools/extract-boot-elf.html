Urban Reign: boot ELF шығару

PS2 ISO ішінен тек SLUS_212.09 файлын шығарады. ISO файл телефоннан шықпайды және интернетке жүктелмейді. 4 ГБ файл толығымен жедел жадқа оқылмайды — тек файлдық жүйенің тақырыптары мен қажетті executable бөлігі оқылады.


ISO таңдалмаған.
GitHub Actions кейін файлдың SHA-256 мәнін тексеріп, тек дәл сәйкес USA executable файлын қабылдайды.
